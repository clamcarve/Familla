基于SPlayer：https://github.com/imsyy/SPlayer 项目，新增多家平台

对于本项目想有更多了解可直接查看原项目

本项目在SPlayer的基础上几乎完全由AI开发


全屏歌词特效、音效和智能节拍移植自 [Folia](https://github.com/chthollyphile/folia-major)（AGPL-3.0），说明见 [src/folia/NOTICE.md](src/folia/NOTICE.md)。

智能节拍需要单独安装 AI 节拍插件（约 133 MB）：可在应用的「特效中心 → 智能节拍」中直接下载，也可以从 [ai-plugin-v1](https://github.com/clamcarve/Familla/releases/tag/ai-plugin-v1) 手动下载后导入。
